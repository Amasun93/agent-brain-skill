# Wiki 知识库搭建技能

## 概述

基于 Andrej Karpathy 的 LLM Wiki 方法论。

**核心理念：** Wiki 是一个**持久化、复利增长的产物**。知识只编译一次，之后持续更新维护，而非每次对话时重新推导。

### 与 RAG 的本质区别

| 对比项 | 传统 RAG | LLM Wiki |
|--------|----------|----------|
| 工作方式 | 每次查询时从原始文档检索片段 | LLM 增量构建并维护持久化 Wiki |
| 知识积累 | 无积累，每次重新发现 | 持续积累，越用越丰富 |
| 交叉引用 | 查询时临时拼凑 | 已预先建立好 |

---

## 三层架构

```
┌─────────────────────────────────────┐
│         Schema（CLAUDE.md）          │  ← 告诉LLM如何维护Wiki的规则
├─────────────────────────────────────┤
│           Wiki（知识库层）            │  ← LLM 拥有并维护
│   index / log / 实体页 / 概念页       │
├─────────────────────────────────────┤
│         Raw Sources（原始资料）        │  ← 不可变，用户维护
│   文章、逐字稿、PPT、图片、资料         │
└─────────────────────────────────────┘
```

---

## 标准目录结构

```
{项目目录}/
├── CLAUDE.md              ← Schema（最关键配置）
├── raw/                   ← 原始资料（不可变，只读）
│   ├── articles/
│   ├── papers/
│   └── assets/           ← 图片等附件
└── wiki/                  ← LLM维护的知识库
    ├── index.md          ← 内容索引（按类别组织）
    ├── log.md            ← 操作日志（仅追加写入）
    ├── entities/         ← 实体页（人物、组织、产品等）
    └── concepts/         ← 概念页（方法论、框架等）
```

## 技能模式

### 模式 A：新建 Wiki 知识库

**触发**：用户说"帮我建一个 wiki 知识库"

**执行步骤**：

1. **确认基本信息**
   - 角色/知识库名称
   - 保存路径
   - 主要知识领域

2. **创建目录结构**

3. **生成 CLAUDE.md**

4. **生成 wiki/index.md 和 wiki/log.md 模板**

---

### 模式 B：Ingest 新素材

**触发**：用户说"ingest 这个文件"、"消化这份资料"

**执行步骤**：

```
新资料进入 raw/
      ↓
LLM 读取并分析
      ↓
提炼关键信息
      ↓
更新 wiki/ 相关页面
      ↓
更新 wiki/index.md
      ↓
追加 wiki/log.md
```

---

## 关键原则

1. **原始资料不可修改** - raw/ 目录下的文件是存档，只读
2. **Wiki 由 LLM 维护** - 索引、交叉引用、矛盾标注由 LLM 自动处理
3. **log.md 仅追加** - 不删除历史记录
4. **知识复利** - 新信息应该与已有知识建立连接
