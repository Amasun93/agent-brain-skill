# 索引文件模板

## 设计原则

**始终加载文件必须 <500 字**，只包含定位信息，不包含详细内容。

## 二级检索机制

### 索引互相引用

**cognitive-memory 索引引用 wiki-builder 索引**:
```markdown
## 相关情境
- 详见: `memory/wiki/index.md` → [条目ID]
- 关键词: 用户搜索"体检" → 先查认知索引 → 定位到L3-001 → 引用wiki索引找到详情
```

**与 wiki-builder 的协作**:
```
用户查询"大卫老师" 
  → cognitive-memory索引 → 定位到行为模式 B-002
  → B-002 引用 wiki/index.md → 找到 L2-2024-001
  → 读取 L2-2024-001 详情
```

---

## 索引更新规则

1. **每次写入新条目** → 更新主索引
2. **每次归档条目** → 从主索引移除
3. **每月一次** → 批量刷新索引
4. **索引损坏时** → 从详情文件重建索引
```
