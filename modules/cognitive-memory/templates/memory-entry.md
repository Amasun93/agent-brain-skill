# 记忆条目模板

## 标准格式

每条记忆条目必须包含以下元数据头部：

```markdown
---
id: [唯一ID，格式: L{X}-[类型]-[YYYYMMDD]-[序号]]
layer: L1/L2/L3/L4/L5
engram: X1-知识/X2-方案/X3-经验/X4-参考
keywords: [逗号分隔的线索词，便于语义检索]
weight: H(高)/M(中)/L(低)
created: [YYYY-MM-DD]
updated: [YYYY-MM-DD]
status: 活跃/待验证/已归档
---
```

## 条目正文结构

### L2 情境层条目（Event）

```markdown
## [事件标题]

### 基本信息
- **时间**: YYYY-MM-DD HH:MM
- **地点**: [地点]
- **参与者**: [人物列表]
- **触发**: [什么引起了这个事件]

### 事件经过
1. [步骤1]
2. [步骤2]
3. [步骤3]

### 结果与产出
- [结果1]
- [结果2]

### 关联提炼
- **初步假设**: [从这件事学到了什么]
- **待验证点**: [需要更多证据才能确认]

### 反思记录
- [Reflect阶段的思考]

---

*原始记录于: YYYY-MM-DD*
```

### L3 行为层条目（Behavior）

```markdown
## [行为模式名称]

### 观察证据
| 时间 | 情境 | 具体行为 | 结果 |
|------|------|---------|------|
| YYYY-MM-DD | [情境] | [行为] | [结果] |
| YYYY-MM-DD | [情境] | [行为] | [结果] |

### 模式提炼
- **触发条件**: [什么情况下会出现这个行为]
- **行为表现**: [具体是什么样的]
- **背后假设**: [为什么会有这个行为]

### 置信度
- 验证次数: X/3
- 反例数: X
- **状态**: 待验证 | 部分验证 | 确认

### 行为指导
- [基于这个模式，我应该怎么应对]
```

### L4 认知层条目（Cognition）

```markdown
## [认知/价值观名称]

### 来源
- **形成时间**: YYYY-MM-DD
- **形成过程**: [怎么形成这个认知的]
- **原始触发**: [什么事件/经历促成的]

### 表现证据
- [具体表现1]
- [具体表现2]
- [具体表现3]

### 内在逻辑
- [为什么用户会持这个观点]
- [这个认知的核心是什么]

### 与其他认知的关系
- **强化**: [哪些认知与此一致]
- **冲突**: [哪些认知与此矛盾]

### 置信度
- 状态: [确认/待验证]
- **注意事项**: [使用这个认知时的注意点]
```

### L5 核心层条目（Core）

```markdown
## [核心特质名称]

### 特质定义
- **核心**: [最本质的描述]
- **表现**: [外在表现]
- **反面**: [相反表现是什么]

### 证据
- **直接证据**: [直接证明这个特质的事件]
- **间接证据**: [侧面印证的事件]

### 深度关联
- **驱动力**: [是什么在驱动这个特质]
- **核心恐惧**: [与这个特质相关的恐惧]
- **满足条件**: [什么情况下这个特质得到满足]

### 一致性记录
| 时间 | 情境 | 是否表现一致 | 备注 |
|------|------|-------------|------|
| ... | ... | ... | ... |

### 使用边界
- **适用场景**: [什么情况下可以据此推断]
- **不适用场景**: [什么情况下不能据此推断]
```

---

## 快速写入格式（对话实时用）

当对话中需要快速记录时，使用简化格式：

```markdown
## [简短标题] L3-X3
- 内容: [核心内容]
- 情境: [在什么情况下观察到的]
- 假设: [初步判断]
- 待验证: [需要验证什么]
- 时间: YYYY-MM-DD
```

## 归档标记格式

```markdown
---
归档时间: YYYY-MM-DD
归档原因: [超过6个月/重复/已证伪/已合并]
合并至: [合并到的条目ID]
---
```
