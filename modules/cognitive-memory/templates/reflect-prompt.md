# 反思提炼 Prompt 模板

## 适用场景

- Heartbeat 定期触发（30分钟一次）
- Calendar 日程触发（深度分析）
- 子Agent 上下文补充

## 标准反思流程

### 第一步：待验证条目扫描

```markdown
## 待验证条目扫描

请扫描以下L2层条目，检查是否有可以进入Reflect阶段的信息：

{扫描结果列表}

### 触发Reflect的条件检查
1. 同一情境重复出现？ → [是/否]
2. 与已有认知冲突？ → [是/否]  
3. 情绪反应异常强烈？ → [是/否]

### 决策
- 可进入Reflect: [条目列表]
- 继续等待: [条目列表]
```

### 第二步：Reflect阶段Prompt

```markdown
## Reflect: [条目标题]

### 原始信息
{原始记录内容}

### 上下文关联
- 相关L3条目: [列表]
- 相关L4条目: [列表]
- 相关L5条目: [列表]

### 反幻觉校验检查

#### 校验1: 小样本检验
- 当前验证次数: X/3
- **判断**: [是否足够支撑提炼]

#### 校验2: 情境依赖检验
- 当前情境: [描述]
- **判断**: [是否过度依赖单一情境]

#### 校验3: 言行一致检验
- 历史一致性: [检查结果]
- **判断**: [是否存在言行不一]

#### 校验4: 可逆性检验
- 提炼结论: [原始假设]
- **改写为可逆表述**: [修正后的表述]

### 反思输出

#### 如果校验通过:
```
## 提炼结论
- 类型: [行为/认知/核心]
- 内容: [提炼后的认知]
- 置信度: [高/中/低]
- 证据: [支撑证据]
- 行为指导: [应该怎么应对]
```

#### 如果校验未通过:
```
## 维持待验证状态
- 原因: [未通过哪项校验]
- 需要: [还需要什么证据]
- 下次验证条件: [何时/何种情况下再检查]
```
```

### 第三步：Experience阶段Prompt（需人工触发）

```markdown
## Experience: [待验证假设]

### 假设内容
{需要验证的假设}

### 验证计划
- 验证方式: [主动创造体验/被动观察]
- 观察周期: [天/周/月]
- 成功指标: [什么情况算验证成功]
- 失败指标: [什么情况算验证失败]

### 执行
- 记录验证开始时间: YYYY-MM-DD
- 预计完成时间: YYYY-MM-DD
- 实际观察记录: [观察过程中持续更新]
```

### 第四步：Realize/Master阶段Prompt

```markdown
## Realize: [整合所有验证结果]

### 验证汇总
| 次数 | 时间 | 情境 | 行为表现 | 是否符合假设 |
|------|------|------|---------|-------------|
| 1 | ... | ... | ... | ... |
| 2 | ... | ... | ... | ... |
| 3 | ... | ... | ... | ... |

### 验证结果
- **验证次数**: X ≥ 3 ✅
- **反例数**: X
- **情境一致性**: [描述]

### 提炼结论

**可升级为L3/L4的结论**:
- 标题: [新认知的名称]
- 内容: [具体内容，务必使用可逆表述]
- 证据链: [简要列出3次验证的证据]
- 行为指导: [基于这个认知应该怎么行动]

### 确认操作
如确认，请执行：
1. 将结论写入对应层级文件
2. 更新条目状态为"已归档"
3. 在log.md中记录操作
```

## 反幻觉校验专用Prompt

当不确定是否过度提炼时，使用以下校验：

```markdown
## 反幻觉校验

### 原始表述
"[待校验的表述]"

### 校验问题
1. 这个结论有 ≥3 次独立验证吗？
   - 如果否 → 不能作为稳定结论，只能标记"初步观察"

2. 结论是否有情境限定？
   - 如果否 → 必须加上"在X情境下"的限定

3. 历史行为是否与结论一致？
   - 如果存在矛盾 → 需要解释矛盾或降级结论

4. 结论是否使用了绝对化词汇？
   - 如果使用了"总是/从不/一定" → 改为"倾向于/通常/倾向于不"

### 输出
- **判断**: 安全提炼 / 需要修正 / 不能提炼
- **修正后表述**: [如果需要修正]
- **下一步**: [归档/继续验证/放弃]
```

## 批量处理Prompt（Heartbeat用）

```markdown
## Heartbeat: 快速扫描

### 时间窗口
扫描自 [日期] 以来的L2待验证条目

### 快速分类
| 条目ID | 类型 | 验证次数 | 操作 |
|--------|------|---------|------|
| ... | ... | ... | ... |

### 执行决策
- **可直接归档**: [列表] → 执行归档
- **需要Reflect**: [列表] → 放入待Reflect队列
- **继续等待**: [列表] → 维持现状

### 时间限制
本次处理不超过5分钟，只处理高优先级条目
```

## 提炼失败时的处理

```markdown
## 提炼失败记录

### 条目ID
[ID]

### 失败原因
- [ ] 小样本（<3次）
- [ ] 情境过度依赖
- [ ] 言行矛盾
- [ ] 表述绝对化
- [ ] 其他: [描述]

### 维持现状
- 当前状态: [状态]
- 何时再检查: [时间/条件]

### 可能的后续
- 如果获得新证据: [描述]
- 如果出现反例: [描述]
```
