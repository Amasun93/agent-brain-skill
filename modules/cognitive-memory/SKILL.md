# Cognitive Memory Skill

**认知记忆系统**：专属理解用户的3D认知架构

---

## 一、架构总览

### 3D认知矩阵

```
                    PromptX (横切轴: 信息是什么)
                          ↓
            X1知识 ─── X2方案 ─── X3经验 ─── X4参考
                         ↑
    ┌────────────────────┼────────────────────┐
    │                    │                    │
    ↓                    ↓                    ↓
  L1 状态            L2 情境              L3 行为
(实时变化)         (事件记录)           (行为模式)
    │                    │                    │
    └────────────────────┼────────────────────┘
                         ↓
              RoleX (提炼轴: 怎么从浅到深)
         encounter → reflect → experience → realize
                         ↓
                       L4 认知
                    (价值观信念)
                         ↓
                       L5 核心
                    (底层驱动力)
```

### 三轴职责

| 轴 | 解决什么问题 | 操作频率 |
|----|-------------|---------|
| **纵深轴(五层)** | 信息放在哪 | 写入时决定 |
| **横切轴(PromptX)** | 信息是什么 | 分类时决定 |
| **提炼轴(RoleX)** | 信息怎么深化 | 定期触发 |

## 四、记忆写入规范

### 标准写入格式

```markdown
---
id: L3-B-20240115-001
layer: L3
engram: X3-经验
keywords: [逗号分隔的线索词]
weight: M
created: 2024-01-15
updated: 2024-01-15
status: 待验证
---

## [标题]

### 观察
- [观察内容]

### 提炼
- [提炼结论]

### 置信度
- 验证次数: X/3
- **状态**: 待验证 | 部分验证 | 确认
```

## 五、反幻觉校验四规则

| 规则 | 说明 | 检查方法 |
|------|------|----------|
| **小样本校验** | 单次观察不能形成结论 | 需要 ≥3 次独立观察 |
| **情境依赖校验** | 判断需标注使用场景 | "在 X 情境下倾向于 Y" |
| **言行一致校验** | 说的和做的是否一致 | 对照行为记录验证 |
| **可逆表述校验** | 结论应该是可修正的 | "目前倾向于..."而非"用户就是..." |
