# PromptX Engram 四分类参考

## 核心原则

**横切轴**：信息的本质类型，解决"信息是什么"

---

## 四分类定义

### X1 知识 (Knowledge)
**定义**：客观存在、可验证的信息事实

**特征**：
- 有真假对错之分
- 不随主观变化
- 可被证伪

**存储位置**：参考文件或外部知识库

**示例**：
```
- 水的沸点是100°C
- Python是一种编程语言
- 北京是中国的首都
```

**不适用的信息**：
```
✗ "用户喜欢蓝色" → 这是推断，不是知识
✗ "这个方法有效" → 这是经验，不是知识
```

---

### X2 方案 (Solution)
**定义**：解决问题的步骤和方法

**特征**：
- 面向目标
- 有执行步骤
- 可复用于类似问题

**存储位置**：经验库/流程文档

**示例**：
```
## 会议组织方案
1. 确定议题和目标
2. 邀请必要参与人
3. 提前发送背景资料
4. 控制时间，确保产出
```

---

### X3 经验 (Experience)
**定义**：亲身经历形成的判断和直觉

**特征**：
- 来源于具体事件
- 带有情境依赖性
- 不一定可泛化

**存储位置**：MEMORY.md 情境记录

**提炼为方案的判断标准**：
```
经验 → 方案的触发条件：
1. 同一情境重复出现 ≥3 次
2. 行动路径基本一致
3. 结果持续正向

经验 → 方案的反例：
- 只有1-2次尝试
- 成功可能来自偶然因素
```

**示例**：
```
## 经验：用户对冗长回复会直接忽略
- 来源：3次观察
- 情境：发送长段解释时
- 行动：现在只给结论，要点不超过3条
```

---

### X4 参考 (Reference)
**定义**：辅助理解但非核心决策的信息

**特征**：
- 提供背景
- 帮助理解
- 不直接驱动行动

**存储位置**：参考文档/附录

**示例**：
```
## 参考：行业术语表
- B2B: Business to Business
- MVP: Minimum Viable Product

## 参考：项目背景
- 项目启动时间：2024-01
- 核心团队规模：5人
```

```
         ├─────────────┼─────────────┼─────────────┼─────────────┤
    L4   │   ——        │  价值观判断  │  信念体系   │  背景资料   │

         ├─────────────┼─────────────┼─────────────┼─────────────┤
```

```
遇到一条信息时，问：
                    ┌─────────────────────┐
                    │ 1. 这是客观事实吗？  │
                    │    (可验证/有对错)   │
                    └─────────┬───────────┘
                              │
              ┌───────────────┴───────────────┐
              ↓                               ↓
            是                              否
              │                               │
              ↓                               ↓
         [X1 知识]                   ┌─────────────────────┐
                                     │ 2. 有执行步骤吗？    │

                                     └─────────┬───────────┘
```

## 分类后的存储决策

| 分类 | 立即使用 | 短期记忆(L2) | 长期沉淀(L3-L5) |
|-----|---------|-------------|-----------------|
| X1 知识 | 上下文 | 不需要 | 按需归档知识库 |
| X2 方案 | 执行   | 不需要 | 经验库/流程文档 |
| X3 经验 | 判断   | 情境记录 | 提炼后归档 |
| X4 参考 | 理解   | 引用索引 | 外部文档链接 |

## 常见分类错误

### 错误1：将推断当作知识
```
✗ 用户喜欢蓝色（知识表述）
✓ 根据3次选择蓝色，推断用户偏好蓝色（经验推断）

✗ 这个方法有效（知识表述）
✓ 在X情境下测试3次都成功（经验记录）
```

### 错误2：将方案当作经验
```
✗ 遇到这种情况就那样做（方案）
✓ 之前在X情境下用了Y方法，成功了（经验）
```

### 错误3：将参考当作方案
```
✗ 用户背景是互联网行业，做内容运营（参考）
✓ 用户是内容运营，教他用AIGC提效（方案）
```
