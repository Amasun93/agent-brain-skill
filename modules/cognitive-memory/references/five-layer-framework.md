# 五层认知架构参考

## 核心原则

**纵深轴**：从表层信息到深层核心，解决"信息放在哪一层"

## 层级定义

### L1 状态层 (State)
**定位**：实时变化的短寿信息，系统运行状态

**内容特征**：
- 当前对话上下文
- 实时情绪状态
- 临时计算/推理中间结果
- 活跃任务状态

**存储位置**：内存/会话上下文（不持久化）

**示例**：
```
- 用户今天刚提到"周末要去上海"
- 当前对话情绪偏负面
- 正在处理"预约医生"任务
```

---

### L2 情境层 (Situation)
**定位**：特定时空背景下的事件记录

**内容特征**：
- 时间、地点、人物、事件
- 可检索的历史事件
- 项目/任务的当前状态
- 情境相关的偏好

**存储位置**：`memory/wiki/`（wiki-builder方式组织）

**索引**：`memory/wiki/index.md`（精准定位，不全量读取）

**保留周期**：默认6个月滚动窗口

**示例**：
```
## 2024-01-15 医疗预约事件
- 地点：和睦家医院
- 人物：大卫老师
- 事件：陪同用户做年度体检
- 结果：发现血压偏高，建议调整饮食
```

---

### L3 行为层 (Behavior)
**定位**：用户行为模式的历史沉淀

**内容特征**：
- 习惯性动作
- 决策倾向
- 交互风格
- 可预测的行为模式

**存储位置**：`memory/cognition/behavior.md`

**更新频率**：按需更新，不频繁变化

**示例**：
```
## 决策风格
- 习惯延迟决策，需要多次催促
- 偏好周末处理重要事务
- 重要决定需要"冷静期"

## 沟通偏好
- 喜欢简洁直接的表达
- 对冗长解释不耐烦
```

---

### L4 认知层 (Cognition)
**定位**：用户认知世界的方式

**内容特征**：
- 价值观（后天形成）
- 信念体系
- 思维模式
- 兴趣领域

**存储位置**：`memory/cognition/cognition.md`

**示例**：
```
## 职业观
- 工作是实现自我价值的手段
- 反对996，支持work-life balance

## 消费观
- 愿意为体验付费
- 不追求奢侈品
```

---

### L5 核心层 (Core)
**定位**：先天特质与底层驱动力

**内容特征**：
- 人格特质（相对稳定）
- 核心需求/恐惧
- 底层驱动力
- 身份认同

**存储位置**：`memory/cognition/core.md`（**不是SOUL.md**）

**边界划分**：
- SOUL.md = Agent的人格设定（Agent怎么说话、思考方式）
- L5 Core = 用户的核心特质（用户的驱动力、恐惧、身份认同）

**示例**：
```
## 核心驱动力
- 追求成长与意义感
- 对混乱和无序有强烈不适

## 核心恐惧
- 被控制，失去自主性
- 停滞不前，虚度光阴
```

---

## 层级关系图

```
         深度增加
           ↑
    ┌─────────────────┐
    │     L5 Core     │  ← memory/cognition/core.md
    │  (用户底层驱动)  │     (≠ SOUL.md)
    ├─────────────────┤
    │  L4 Cognition   │  ← memory/cognition/cognition.md
    │  (用户价值观)   │     (从USER.md迁移)
    ├─────────────────┤
    │   L3 Behavior   │  ← memory/cognition/behavior.md
    │  (用户行为模式)  │     (从USER.md迁移)
    ├─────────────────┤
    │  L2 Situation   │  ← memory/wiki/index.md + 详情
    │  (情境事件)     │     (wiki-builder方式组织)
    ├─────────────────┤
    │    L1 State     │  ← 会话内存(不持久化)
    │  (实时状态)     │
    └─────────────────┘
           ↓
      表层信息
```

---

## 跨层信息流动

```
L5 Core ──决定──→ L4 Cognition (特质影响价值观)
L4 Cognition ──塑造──→ L3 Behavior (价值观驱动行为)
L3 Behavior ──累积──→ L2 Situation (行为产生事件)
L2 Situation ──提炼──→ L4 Cognition (经验修正认知)
```

**提炼原则**：低层经验可提炼为高层认知，但需要显式触发和确认。

---

## 与wiki-builder的职责划分

| 层级 | 内容类型 | 管理Skill | 存储位置 |
|-----|---------|----------|---------|
| L1 | 实时状态 | 无（不持久化） | 会话内存 |
| L2 | 情境事件详情 | **wiki-builder** | `memory/wiki/` |
| L3 | 行为模式 | **cognitive-memory** | `memory/cognition/behavior.md` |
| L4 | 认知/价值观 | **cognitive-memory** | `memory/cognition/cognition.md` |
| L5 | 核心特质 | **cognitive-memory** | `memory/cognition/core.md` |
| — | Agent人格 | SOUL.md（独立维护） | 项目根目录 |

**协作方式**：cognitive-memory的索引引用wiki-builder的索引，形成二级检索。
